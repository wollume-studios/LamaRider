Metalama tooling for Rider: see which aspects touch your code, what they generate, test them and debug them. The Rider counterpart of the Visual Studio extension "Metalama Tools".

LamaRider tool window

Every aspect class of the solution and its packages, filtered and grouped, with its documentation and Go to source (also for library aspects). Select one to see its targets with their transformations and diagnostics. Track Caret shows the aspects at the caret instead. Refreshes on its own.

Code Vision and transformed code

  • Above declarations: the aspects a fabric, inheritance etc. adds, transformed code, and applied to N targets on aspect classes. Tooltips say where an aspect comes from. Aspects on parameters and return values get inlay hints. Can show only aspect counts instead.
  • A click shows the aspects grouped by member, parameter and return value; clicking one goes to its source or shows it in the LamaRider window.
  • Show Transformed Code: one declaration after all aspects, in a popup, with a diff toggle.
  • Metalama Diff: source and transformed code of a whole file side by side.

Aspects into code

  • Add [Log] as attribute (Alt+Enter on a declaration name): writes an aspect that a fabric, inheritance or another aspect adds as an attribute.
  • Replace with transformed code: metalama divorce for one declaration.

T# template highlighting

Compile-time code in templates is tinted; meta.* and compile-time variables stand out.

Metalama errors

  • Errors such as LAMA0037 are underlined seconds after a save, also while Rider's Metalama analysis waits for a build (LAMA0118).
  • Errors without a location (e.g. an exception in a fabric) show in an info bar.
  • Alt+Enter: LAMA documentation, Build project to resume Metalama analysis; optional build on save.

Aspect tests

Create Metalama aspect test (Alt+Enter on an aspect class) adds a prefilled test, creating the test project when needed. Run or debug it from the gutter. When the output differs from the .t.cs, an info bar offers Compare and Accept all. While debugging, breakpoints in your aspects, templates and fabrics stop. Rider's Test Runner discovery, which aspect tests need, is set up for you.

Metalama Premium code

A warning on every use of a Metalama Premium component (code fixes, validation, architecture, Azure / Redis caching), which needs a Metalama Professional license. Alt+Enter puts it in #if METALAMA_PREMIUM or sets up free and Premium builds of the project.

Debugging transformed code

Debug with LamaDebug selects (or adds) Metalama's LamaDebug configuration and starts debugging the transformed code. Or debug transformed code in every build configuration.

Settings

Settings › Tools › LamaRider: Code Vision display, build on save, debugging, and the Rider setup for aspect tests.

Works with Metalama 2026.x and Rider 2026.2 and 2026.3. Metalama's Premium components (e.g. code fixes from Metalama.Extensions.CodeFixes) need a Metalama Professional license; without one the build fails with LAMA0806. How to use each feature.

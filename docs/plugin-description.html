Metalama tooling for Rider: see which aspects touch your code, what they generate, and debug the result. The Rider counterpart of the Visual Studio extension "Metalama Tools".

LamaRider tool window

Aspect classes grouped by project and package, with their documentation. Select one to see every target (project, namespace, type, member) with the transformations it causes and the diagnostics it reports. Library aspects open their sources or decompiled code. The window refreshes on its own when code, projects or packages change.

Code Vision and transformed code

  • N aspects above every declaration an aspect touches; applied to N targets above aspect classes.
  • Show Transformed Code: the transformed code of one declaration in a popup, with the aspects that changed it.
  • Metalama Diff: source and transformed code of a whole file side by side.

T# template highlighting

Compile-time code in templates is tinted; meta.* and compile-time variables stand out (Settings › Editor › Color Scheme › Metalama T#).

Metalama errors

  • An info bar on C# editors when Metalama reports errors: go to the error, open the LAMA documentation, build.
  • Errors without a location, such as LAMA0042 aspect ordering, are underlined on your aspect classes.
  • Alt+Enter in aspect and template code: Build project to resume Metalama analysis (LAMA0118), or build on save.

Aspect tests

Alt+Enter on an aspect class: Create Metalama aspect test adds a prefilled test file to the aspect test project next to the aspect's project, creating the project when there is none. Run the test, then Accept Metalama test output saves its output as the expected .t.cs.

Debugging transformed code

Debug with LamaDebug selects Metalama's LamaDebug configuration (adding it to the .sln or .slnx when missing) and starts debugging: step into aspect code or set breakpoints in the transformed files.

Settings

Settings › Tools › LamaRider: build after aspect changes, debug transformed code in every configuration, and the Rider setup Metalama aspect tests need (shows whether it is in place).

Works with Metalama 2026.x and Rider 2026.3. No Metalama license needed for the IDE features.
